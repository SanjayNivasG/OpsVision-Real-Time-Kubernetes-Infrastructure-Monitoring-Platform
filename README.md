# OpsVision – Real-Time Kubernetes Infrastructure Monitoring Platform

## Project Overview

OpsVision is a cloud-native DevOps project that automates application deployment and infrastructure monitoring using AWS, Jenkins, Docker, Kubernetes, Prometheus, and Grafana.

## Architecture

Developer → GitHub → Jenkins → Docker → DockerHub → Kubernetes → Prometheus → Grafana

## Technologies Used

* AWS EC2
* Jenkins
* Docker
* DockerHub
* Kubernetes
* Prometheus
* Grafana
* Node Exporter
* kube-state-metrics

## Features

* CI/CD Automation
* Docker Containerization
* Kubernetes Orchestration
* Real-Time Monitoring
* Infrastructure Health Tracking
* Resource Utilization Monitoring

## Monitoring Metrics

* CPU Usage
* Memory Usage
* Disk Usage
* Network Usage
* Pod Metrics
* Deployment Metrics
* Container Metrics
* Node Metrics

## Dashboards

### Node Exporter Full

Shows:

* CPU
* Memory
* Disk
* Network

### Kubernetes Cluster (Prometheus)

Shows:

* Nodes
* Pods
* Containers
* Deployments

### Kubernetes Cluster Monitoring (via Prometheus)

Shows:

* Cluster CPU
* Cluster Memory
* Cluster Filesystem
* Network Statistics

## Outcome

Successfully deployed and monitored Kubernetes infrastructure with centralized monitoring and visualization using Prometheus and Grafana.
